# Digital Forensics Learning Lab

A step-by-step digital forensics learning repository by Alex.

## Learning Principles

- Use only self-created data or explicitly authorized evidence.
- Preserve original evidence and analyze working copies.
- Verify file integrity with SHA-256.
- Record commands, observations, and analysis limitations.
- Never publish personal information or real case evidence.

## Day 1 — Forensics Basics and Evidence Integrity

Completed:

- Created a synthetic evidence file.
- Recorded its SHA-256 hash.
- Created and verified a working copy.
- Modified only the working copy.
