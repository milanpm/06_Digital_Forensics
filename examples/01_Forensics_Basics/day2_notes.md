# Day 2 — File Metadata and Timestamp Analysis

Author: Alex

## Objectives

- Examine file size, permissions, and timestamps.
- Understand Access, Modify, Change, and Birth times.
- Compare normal copying with metadata-preserving copying.
- Observe metadata changes caused by content modification.
- Verify that timestamp changes do not alter a content hash.
- Interpret timestamps together with their time zone.

- Windows 10
- Git Bash
- NTFS
- Time zone: KST (`+0900`)
